
# 📝 Lista de Exercícios 01 - Formação Dev. Full Stack Jr T1 - +praTi & Codifica 

Este repositório contém as resoluções da Lista de Exercícios 01, que fazem parte da formação oferecida pelo projeto +praTi & Codifica. Os exercícios foram desenvolvidos em JavaScript utilizando Node.js e abrangem operações fundamentais, estruturas de controle condicional (`if`, `else`, `switch`) e estruturas de repetição (`for`, `while`).

## 📂 Como acessar o projeto

Clone este repositório usando o Git:

```bash
git clone https://github.com/ingridmoitinho/lista_exercicios_01_maispraTi.git
cd lista_exercicios_01_maispraTi
```

## 🛠️ Requisitos

- Ter o Node.js instalado
- Instalar a biblioteca readline-sync (para entrada via terminal):

```bash
npm install readline-sync
```

## ⚠️ Problemas com o PowerShell?
Se ao executar npm install aparecer um erro de permissão, use o terminal cmd em vez do PowerShell:

1. No VS Code, abra o terminal com:

```bash
Ctrl + j
```

2. Clique no botão + ao lado da aba do terminal.

3. Selecione o terminal cmd (Prompt de Comando).

4. Execute novamente o comando:

```bash
npm install readline-sync
```

## ▶️ Como executar

1. Abra o terminal na pasta onde os arquivos foram clonados.
2. Execute um dos arquivos com:

```bash
node nome_do_arquivo.js
```

Por exemplo:

```bash
node ex01_par_ou_impar.js
```
